GINGER TAPE LUX LANDING PAGE

Kako da pokreneš:
1. Raspakuj ZIP.
2. Otvori folder u VS Code.
3. Otvori index.html.
4. Desni klik -> Open with Live Server.

Fajlovi:
- index.html — struktura stranice
- style.css — luksuzni dizajn
- script.js — WhatsApp porudžbina
- assets/ — slike proizvoda

Kako da promeniš WhatsApp broj:
Otvori script.js i promeni:
const WHATSAPP_NUMBER = "381658005557";

Format mora biti 381 + broj bez prve nule.
Primer: 065 800 5557 -> 381658005557
